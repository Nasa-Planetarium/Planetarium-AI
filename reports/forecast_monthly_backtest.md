# 월말 관측을 갱신하는 일별 열원 확률 평가

평가 기간을 달력 월 단위로 나눕니다. 하나의 예측값은 지역마다 특정 현지 태양시 날짜에 기준 열원이 한 번 이상 탐지될 확률입니다. 각 월의 시작 시점에 그 월의 마지막 날까지 필요한 모든 일별 확률을 만듭니다.

| 평가 대상 | 모델에 제공하는 마지막 실제 관측 | 예측 및 채점 날짜 |
|---|---|---|
| 2026년 1월 | 2025년 12월 31일 | 2026년 1월 1~31일 |
| 2026년 2월 | 2026년 1월 31일 | 2026년 2월 1~28일 |
| 2026년 3월 | 2026년 2월 28일 | 2026년 3월 1~31일 |

다음 월의 기준일로 이동할 때 직전 월의 실제 관측을 반영합니다. 예측은 목표 월 시작 시점에 고정합니다. 월말 관측이 불완전하면 당시까지 전 세계 관측이 정상이던 마지막 날짜를 공통 기준일로 삼습니다. 2026년 5월은 4월 26일을 기준으로 예측해 5월 1~31일을 채점했고, 2026년 6월은 5월 30일을 기준으로 예측해 6월 1~30일을 채점했습니다.

## 대상과 모델

- 배포본 v1.2의 전 세계 0.5° 육지 격자 69,215개와 2° 범위 5,347개를 평가합니다. 범위의 정답은 범위 안에서 기준 열원이 한 건 이상 탐지된 날입니다. 2025년은 1~12월, 2026년은 1~10월입니다. 배포본이 11월 중순까지만 제공되므로 월말까지 관측 날짜가 있는 가장 최근 달은 10월입니다.
- 목표 월의 모든 날짜에 확률을 계산하고, 위성 상태가 정상인 지역·날짜의 정답으로 Brier score, log loss, PR-AUC를 계산합니다. 월별 CSV에는 공통 기준일, 예측 일수, 채점 가능한 날짜 수, 전체 지역·일 수, 채점 행 수와 실제 탐지율도 기록합니다.
- 계절 발생률, 계절 Markov 1·2차, 로지스틱 회귀, XGBoost는 기준일까지 실제 관측으로 지역별 계절·전이 통계를 갱신합니다. 그 통계와 기준일 이진 상태로 첫날을 시작하고 확률 상태를 매일 다음 날짜로 전달합니다. 로지스틱 회귀와 XGBoost 자체는 2016~2022년 자료로 학습하고 2023년으로 보정한 가중치를 사용합니다.
- 최근 탐지율 보정과 [Hugging Face 체크포인트 네 종의 확률 보정](forecast_benchmark.md#hugging-face-사전학습-모델-비교)은 기준일까지의 최근 64일을 봅니다. 각 체크포인트의 출력에 2023년 월말 기준 이력으로 적합한 일차별·공간 단위별 확률 보정기를 적용합니다. 목표 월 전체에 대한 예측은 기준일의 이력에서 계산합니다.
- 지역·기간 조회 방법과 앞선 짧은 리드 비교는 [기존 일별 실험과 조회 예시](forecast_benchmark.md)에 있습니다.

## 재현

저장소 루트에서 실행합니다. Hugging Face 후보에는 [기존 실험의 별도 Python 환경](forecast_benchmark.md#재현)을 사용할 수 있습니다.

```bash
uv run python -m planetarium.modeling.monthly_occurrence_benchmark local --device cpu --threads 16
uv run python -m planetarium.modeling.monthly_occurrence_benchmark history --device cpu

forecast_python="${XDG_CACHE_HOME:-$HOME/.cache}/planetarium-forecast-hf/bin/python"
"$forecast_python" -m planetarium.modeling.monthly_occurrence_benchmark timesfm3 --batch-size 1536
"$forecast_python" -m planetarium.modeling.monthly_occurrence_benchmark chronos2 --batch-size 384
"$forecast_python" -m planetarium.modeling.monthly_occurrence_benchmark chronos_bolt --batch-size 512
"$forecast_python" -m planetarium.modeling.monthly_occurrence_benchmark tirex2 --batch-size 512
uv run python -m planetarium.modeling.monthly_occurrence_benchmark report
```

모든 명령은 기본값으로 2025년 1월부터 마지막 달력 월까지 평가합니다. 동일한 `--start YYYY-MM --end YYYY-MM` 인자로 대상 월을 지정할 수 있습니다. 개별 실행은 월별 지표를 배포본·평가 기간별 캐시에 저장합니다. `report`를 다시 실행하면 완료된 모델의 결과를 이 문서와 CSV에 반영합니다.

# 위치별 30일 일별 `value` 예측

과학자 탭의 달력 월 합계는 별도로 검증했습니다. [월간 LightGBM L1 선택 근거와 백엔드 연동안](../docs/monthly_activity_forecast.md)

**일별 예측의 기본 모델은 LightGBM L1**입니다. 전 세계 14,147개 위치·범위에서 2025년과 2026년 1~10월을 검증한 결과, 비교한 모델 중 일별 규모 평균 WAPE가 가장 낮았습니다. **30일 누적량의 절대 오차를 줄이는 목적에는 학습 0의 80%를 덜어낸 LightGBM L1**이 두 기간 모두 가장 좋았습니다.

| 평가 목적 | 모델 | 2025 WAPE | 2026년 1~10월 WAPE |
|---|---|---:|---:|
| 일별 `value` | LightGBM L1 | **81.79%** | **83.79%** |
| 30일 합계 | LightGBM L1, 학습 0의 80% 제거 | **55.77%** | **48.77%** |

일별 기본 모델은 보수적입니다. 일별 예측 전체량의 규모 평균 편향은 2025년 **−55.09%**, 2026년 **−57.21%**입니다. 양이 큰 날까지 포함한 누적 기대량의 편향을 줄이는 목적에는 XGBoost Tweedie도 비교할 만합니다. 같은 지표에서 각각 **+3.97%**, **+0.26%**였고 일별 WAPE는 각각 109.55%, 109.79%였습니다.

## 데이터와 검증

- 정답은 v1.2 `harmonized_cell_day.parquet`의 지역별 `value` 합입니다. 단위는 S-NPP 기준 환산 탐지량이며 소수도 유지합니다. 날짜는 칸별 현지 태양일입니다. 월 보정분인 `residual_month`는 일별 목표에 넣지 않습니다. [v1.2 릴리스](../docs/release_v1.2-2026-11-15.md) · [일별 합계 계약](../docs/api_contract.md#summaryaoibboxpolygonstartendfreqdaymonth)
- 2017년부터 `snpp_observed`와 `n20_bridge`를 사용했습니다. `satellite_day_status.parquet`에서 각 지역의 경도에 필요한 UTC 날짜의 기준 위성 자료가 모두 정상인 날은 집계 행이 없으면 0입니다. 자료가 빠진 날은 학습·채점에서 제외합니다. 이 관측 마스크는 위성 파일 단위이므로 특정 칸의 궤도 통과나 구름까지 확인할 수 없습니다.
- 남극을 제외한 전 세계 육지를 대상으로 0.1° 칸 3,000개, 0.5° 사각형 4,000개, 2° 사각형 5,347개, 1.3°×0.7° 사각형 1,800개를 비교했습니다. 2° 사각형은 육지와 겹치는 전수입니다. 0.1° 칸은 0.2° 간격 후보의 중심이 육지인 경우에서 뽑았고 나머지 두 크기의 표본은 육지와 겹치는 후보에서 뽑았습니다. 표본 선정에 탐지 유무를 쓰지 않았습니다. 공간 범위는 학습과 평가에 공통으로 사용했습니다. 평가 수치를 다른 크기, 합집합, 전혀 새로운 위치로 일반화하는 데에는 추가 검증이 필요합니다.
- 매월 직전 월말까지의 실제 데이터로 기준일을 정했습니다. 월말 관측이 빠져 있으면 직전 정상 관측일이 기준일입니다. 기준일 +1일~+30일을 한 번에 예측하고 그 사이의 실제값으로 갱신하지 않았습니다. 다음 월별 평가에서 새 관측을 입력으로 받습니다. 예를 들어 2026년 5월 회차는 4월 26일을 기준으로 4월 27일~5월 26일을 예측했습니다.
- 2025년 12회와 2026년 1~10월 10회에서 동일한 정답을 사용했습니다. 유효 일별 예측은 각각 4,993,879건과 3,842,375건입니다. 30일 합계는 30일 전부 관측 가능한 지역·회차 141,470건과 42,441건에서만 비교했습니다. 고정 길이 30일이므로 월별 회차의 날짜가 일부 중복되거나 월 경계를 넘을 수 있습니다.
- 학습은 2018년 이후 예측 기준일과 2024-12-31까지의 정답만 사용했습니다. 지역별 최근 3·7·14·30·90일 평균, 최근 최대값과 활동 빈도, 예년 같은 시기 평균, 위치·면적·예측 시차를 입력했습니다. 회귀 모델은 지역의 직전 365일 평균에 1을 더한 값으로 목표를 스케일링했습니다. 표준 학습 표본은 2,602,649건입니다. Random Forest와 Extra Trees는 계산량을 제한해 이 중 고정 표본 400,000건을 사용했습니다.
- WAPE는 `Σ|예측 − 실제| / Σ실제`입니다. 월별 분자·분모를 연도 안에서 합친 후, 지역 규모 네 종류의 WAPE를 같은 비중으로 평균했습니다. MAE, RMSE, 부호 있는 합계 편향, 실제 양수일 MAE, 실제 0일 평균 예측량은 규모별로 기록했습니다. 0 고정 예측의 WAPE는 100%입니다. [월별 지표](forecast_value_monthly.csv) · [규모·연도·예측 시차별 지표](forecast_value_yearly.csv)

## 관측 0을 줄인 학습

표준 학습의 **88.96%**가 관측된 0이었습니다. 평가에서도 관측된 0은 2025년 89.12%, 2026년 88.35%였고, 0.1° 칸에서는 두 기간 모두 99%가 넘었습니다. 실험은 학습에서만 양수 287,289건을 전부 보존하고 관측 0을 무작위로 남겼습니다. 0을 50% 남긴 모델은 1,445,910건, 20% 남긴 모델은 750,708건으로 학습했습니다. 평가 날짜와 0의 비율은 모든 모델이 같습니다.

- **가중치 없는 제거**는 LightGBM L1과 XGBoost L1에 적용했습니다. 양수일을 더 잘 맞힐 수 있지만 실제 0인 날에도 양수가 커질 수 있습니다.
- **역확률 가중치**는 20% 남은 0의 학습 가중치를 5배로 두었습니다. LightGBM L1에서 전체 학습과 일별 WAPE가 약 0.24%p와 0.18%p 이내로 비슷했습니다.
- **2단계 Hurdle**은 먼저 `value > 0` 확률을 학습하고, 양수만으로 학습한 Gamma 회귀량과 곱했습니다. 0을 20% 남긴 버전은 학습된 확률의 오즈에 0.2를 곱해 원래 0 비율을 복원했습니다. 일별 WAPE는 두 해 모두 전체 데이터 Hurdle보다 소폭 개선됐고 LightGBM L1보다 높았습니다.

0.1° 칸에서 0의 80%를 제거한 LightGBM은 2025년 양수일 MAE를 **3.37 → 2.93**으로 줄였습니다. 동시에 실제 0인 날의 평균 예측량은 **0.0013 → 0.0130**으로 늘어 일별 WAPE가 **100.39% → 127.57%**로 높아졌습니다. 단일 0.1° 칸에서는 전체 데이터 LightGBM L1도 두 해 모두 0 고정 예측의 일별 WAPE를 넘어서지 못했습니다. 위치 한 칸과 여러 칸이 포함된 지역 범위의 성능은 구분해서 해석해야 합니다.

### Hugging Face 모델

각 모델에 과거 256일의 `value`를 넣어 30일을 직접 예측했습니다. 입력 이력의 관측 결측은 해당 이력의 평균으로 채웠습니다. 백본은 동결하고 2024년 1·4·7·10월 회차에서 모델의 10·50·90 분위수, 계절 평균, 최근 30일 평균을 섞는 비음수 회귀 계수만 규모별로 학습했습니다. TiRex-2가 이 조건에서 사전학습 후보 중 일별 WAPE가 가장 낮았습니다. [TimesFM 3.0](https://huggingface.co/google/timesfm-3.0-pytorch) · [Chronos-2](https://huggingface.co/amazon/chronos-2) · [Chronos-Bolt](https://huggingface.co/amazon/chronos-bolt-base) · [TiRex-2](https://huggingface.co/NX-AI/TiRex-2)

HistGradientBoosting Poisson은 큰 이상 예측으로 수치가 발산해 선택에서 제외했습니다. MLP는 최대 42회 학습 시점에 수렴 경고가 났으며 그 시점의 예측을 기록했습니다. 2025년과 2026년 지표는 같은 사후 비교에 사용했으므로, 모델을 더 튜닝한 뒤에는 별도 미래 구간에서 다시 검증해야 합니다.

## 실행 방법

v1.2 데이터를 설치한 작업 폴더에서 실행합니다. 이 명령은 선택한 모델을 학습하고 `data/interim/value_forecast/results/`에 모델과 지표를 생성합니다. 새 체크아웃에서는 모델 파일을 생성한 뒤 조회합니다.

```bash
uv sync --locked --no-dev
uv run --locked --no-dev python -m planetarium.modeling.value_benchmark \
  --models lightgbm_l1 lightgbm_l1_zero20
```

```python
import polars as pl

from planetarium import store

regions = [
    {"id": "seoul", "point": [126.978, 37.5665]},
    {"id": "kwazulu", "bbox": [29, -30, 31, -28]},
]
daily = store.value_forecast(regions)
for_total = store.value_forecast(regions, model="lightgbm_l1_zero20")
total30 = for_total.group_by("region_id").agg(pl.col("value").sum().alias("value_30d"))
```

좌표는 그 점을 포함하는 0.1° 칸을 사용합니다. 사각 범위와 합집합은 포함된 격자 중심의 `value`를 합산합니다. `as_of="2025-03-31"`처럼 날짜를 지정하면 그 날짜까지 확인된 관측을 사용합니다. 데이터 기준일을 생략한 실제 조회에서 동·서경을 함께 요청한 경우, 공통 기준일은 2026-11-12였고 예측은 2026-11-13~2026-12-12였습니다.

전체 비교는 CPU 후보와 GPU 후보를 별도 프로세스로 실행할 수 있습니다. `--out`을 같은 폴더로 지정하면 모델별 지표가 그 폴더에 모입니다. CPU 모델만 재실행하려면 모델 목록을 생략합니다. 이 경우 기준 3개와 학습 17개가 실행됩니다.

```bash
uv run --locked --no-dev python -m planetarium.modeling.value_benchmark --prepare
uv run --locked --no-dev python -m planetarium.modeling.value_benchmark
uv run --locked --no-dev python -m planetarium.modeling.value_results
```

RTX 4090에서 XGBoost와 사전학습 모델을 실행했습니다. XGBoost는 `--models xgboost xgboost_l1 xgboost_l1_zero20 --device cuda`로 실행할 수 있습니다. 사전학습 모델은 CUDA PyTorch 환경에 `polars`, `shapely`, `filelock`, `scipy`, `joblib`, `timesfm[torch]==3.0.2`, `chronos-forecasting==2.3.2`, `tirex-2==0.5.0`를 설치하고 `python -m planetarium.modeling.value_benchmark --models timesfm3 chronos2 chronos_bolt tirex2 --device cuda --batch-size 128`로 실행합니다. 체크포인트 리비전은 어댑터에 고정되어 있습니다.
